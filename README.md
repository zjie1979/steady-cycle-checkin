# 循环轻记

适合通过 iPhone Safari 添加到主屏幕的静态饮食打卡 App。

- 今日：原帖食谱的食物和饮品可逐项勾选，按参考份量计入当天热量。可手动补记其他饮食和备注，查看食物、饮品和全天已记热量，并完成每日打卡。
- 循环：健康饮食 → 轻断食 → 健康饮食 → 随便吃。选择起始日期后按日历轮转，第五天回到第 1 天。每一天都有独立的原帖食谱页，今日也会显示对应食谱。也可以打开自订日序。
- 记录：浏览按日期保存的历史记录。
- 说明：分开查看稳健版规则、可选早餐、四日食谱示例和热量估算，以及安装和本机存储说明。

规则来自八戒的小主（SAWYER）于 2025-09-10 发布的[稳健版规则视频](https://www.xiaohongshu.com/explore/68be51e9000000001b0341e7)。四天日序和打卡选项来自她于 2025-10-25 发布的[稳健版四日食谱](https://www.xiaohongshu.com/explore/68fa5840000000000401392f)。项目与原作者无关联。

参考热量依据和估算份量见 App 的「说明 → 食谱热量怎么算」。估算热量按打卡当时的参考值存入当天记录。

旧版已开始的四天循环在下一轮切换到原帖日序，保留已有打卡和饮食记录。

在 iPhone Safari 打开网站，点「分享 → 添加到主屏幕 → 添加」。首次在线访问后可离线使用。记录保存在当前浏览器中，不需要登录，也不会自动上传。清除网站数据会丢失记录。

GitHub Pages 的发布来源为 `main` 分支根目录。
