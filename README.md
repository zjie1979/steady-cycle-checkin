# 循环轻记

适合通过 iPhone Safari 添加到主屏幕的静态饮食打卡 App。

- 今日：记录食物、饮品和备注，分别汇总食物和饮品热量，支持每日打卡。
- 循环：自己设置健康饮食日和轻断食日的顺序，选择起始日期，查看本轮进度。
- 记录：浏览按日期保存的历史记录。
- 说明：查看原作者答疑、安装和本机存储说明。

来源为八戒的小主（SAWYER）于 2025-10-09 发布的[稳健版答疑](https://www.xiaohongshu.com/explore/68e5f878000000000401213c)。尚未核实稳健版完整日序，因此 App 不预设循环顺序或每日热量目标。项目与原作者无关联。

在 iPhone Safari 打开网站，点「分享 → 添加到主屏幕 → 添加」。首次在线访问后可离线使用。记录保存在当前浏览器中，不需要登录，也不会自动上传。清除网站数据会丢失记录。

GitHub Pages 的发布来源为 `main` 分支根目录。
