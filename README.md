# 循环轻记

适合通过 iPhone Safari 添加到主屏幕的静态饮食打卡 App。

- 今日：按当天日型逐项勾选饮食规则，按需记录实际饮食、热量和备注。
- 循环：健康饮食 → 轻断食 → 健康饮食 → 随便吃。选择起始日期后按日历轮转，第五天回到第 1 天。点开任意一天可查看打卡规则。也可以打开自订日序。
- 记录：按日期查看已勾选的规则、饮食条目和打卡状态。
- 说明：查看稳健版规则、可选早餐，以及安装和本机存储说明。

打卡规则按八戒的小主（SAWYER）于 2025-09-10 发布的[稳健版规则视频](https://www.xiaohongshu.com/explore/68be51e9000000001b0341e7)整理。四天日序按她于 2025-10-25 发布的[稳健版四日食谱](https://www.xiaohongshu.com/explore/68fa5840000000000401392f)排列。项目与原作者无关联。

勾选规则和记录食物分开保存。历史饮食条目可继续在「记录」里查看。

旧版已开始的四天循环在下一轮切换到原帖日序，保留已有打卡和饮食记录。

在 iPhone Safari 打开网站，点「分享 → 添加到主屏幕 → 添加」。首次在线访问后可离线使用。记录保存在当前浏览器中，不需要登录，也不会自动上传。清除网站数据会丢失记录。

GitHub Pages 的发布来源为 `main` 分支根目录。
